Secure Content Portal

A role-based portal for sharing training and reference content (video, PDF, HTML) with Google sign-in.

This is a student take-home project built to a screening brief. Admins upload video, PDF and HTML content; viewers sign in with their Google account to watch and read it inline, without a working path to download the original file.
